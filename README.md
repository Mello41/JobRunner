# JobRunner

Автоматизированный планировщик заданий (доменная часть проекта "JobRunner")
C# + Quartz (библиотеки классов)
Основной функционал описан внизу (см. Планируемый функционал)

В решении несколько проектов (3):

	JobRunner.Core - библиотека классов (.NET Standart 2.0 с версией языка C# 9.0)
			доменная модель, DTO, интерфейсы
		Зависимости: 
			System.Text.Json v6.0.11
			System.ComponentModel.DataAnnotations v5.0.0

	JobRunner.Quartz - библиотека классов (.NET 10.0)
			реализация интерфейса IJobScheduler с библиотекой Quartz
		Зависимости: 
			JobRunner.Core (доменная модель)
			
			Microsoft.Extensions.DependencyInjection.Abstractions v10.0.7
			Quartz v3.18.0
			Quartz.Extensions.Hosting v3.18.0
			Quartz.Extensions.DependencyInjection v3.18.0
			
	JobRunner.Domain.Tests - тестовый проект xUnit
		тесты для JobRunner.Quartz
		
# Планируемый функционал:
	1. Автоматизация процессов с действиями у задачи (CRUD)
	2. Настройки расписания задачи (единый формат, который не зависит от CRON и тд)
		
	3. Параллельное выполнение задачи
	4. Метаданные объекта задачи
	5. Метки (категории) задач
		Базовые (заранее заданные) метки (типичные системные)
		Создание своих меток
	6. Уведомления 
		до/после выполнения (выбор)
		тип уведомления и реализация (на сервере)
		приоритет уведомления
	7. Указание исполняемого файла задачи
	8. Шифрование аргументов задачи (чувствительные данные)
		Выборочное шифрование аргументов
		
	9. 
	10. 
	11. Статусы (стоп/выполняется, ошибка, успешно завершена без ошибки) 
	12. рекурсивный запуск задачи (когда закончилась - запуск через время) (не параллельное выполнение)
	13. 
	
	Коллаборация функционала с UI частью (Avalonia)
		1. Фильтрация одновременно по нескольким параметрам (название, метки, группа, автор)
			Поиск задач в виде одновременной фильтрации (на стороне UI) (названия, метки...)
			Группировка задач (одновременно запуск и остановка) по меткам
		2. Прямое указание частоты выполнения задачи (раз в 12 часов и тд...)
		3. Вывод последней ошибки прямо в программе
	
	задания категории "мечта"
		сохранение выбранных задач по конфигурацию (по метке), чтобы не потерять и передавать на компьютеры
