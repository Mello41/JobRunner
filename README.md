# JobRunner

Автоматизированный планировщик заданий (доменная часть проекта "JobRunner")
C# + Quartz (библиотеки классов)
Основной функционал:
1. Запуск задач windows (как в планировщике)
2. Управление свойствами задач
3. Автоматизация управлением задач (продление и тд.)
4. Другой (пока определение)

В решении несколько проектов (4):

	JobRunner.Core - библиотека классов (.NET Standart 2.0 с версией языка C# 9.0)
			модели данных, шифрование, DTO, интерфейсы
		Зависимости: 
			System.Text.Json v6.0.10
			System.ComponentModel.DataAnnotations v5.0.0

	JobRunner.Quartz - библиотека классов (.NET 10.0)
			реализация интерфейса IJobScheduler с библиотекой Quartz
		Зависимости: 
			JobRunner.Core (доменная модель)
			
			Microsoft.Extensions.DependencyInjection.Abstractions v10.0.7
			Quartz v3.18.0
		
# Планируемый функционал:
	1. Автоматизация процессов выполнения задачи (CRUD)
	2. Прямое указание частоты выполнения задачи (раз в + в 12 часов и тд...)
	3. Фильтрация одновременно по нескольким параметрам (название, метки, группа, автор)
	4. Поиск задач в виде одновременной фильтрации (на стороне UI) (названия, метки...)
	5. Параллельное выполнение задачи
	6. Выборочное шифрование аргументов
	7. Вывод последней ошибки прямо в программе и в метаданных объекта задачи
	8. Метки (категории) задач
		Группировка задач (одновременно запуск и остановка) по меткам
		Базовые (заранее заданные) метки (типичные системные)
	9. Уведомления до/после выполнения (выбор) + кому
	10. сохранение выбранных задач по конфигурацию (по метке), чтобы не потерять и передавать на компьютеры
		(задание категории "мечта")
	11. Статусы (стоп/выполняется, ошибка, успешно завершена без ошибки) 
	12. рекурсивный запуск задачи (когда закончилась - запуск через время) (не параллельное выполнение)
	13. Указание исполняемого файла задачи
